# Ai 365 AI AGENT - 교육 에이전트 (데모)

[![tests](https://github.com/MCB-Ai365/ai365.ai.agent.kd/actions/workflows/test.yml/badge.svg)](https://github.com/MCB-Ai365/ai365.ai.agent.kd/actions/workflows/test.yml)

AI가 외부 자료를 수집해 **저작권 리스크를 판정**하고, 검증을 통과한 것만 **SharePoint에 비가역 적재**한 뒤, 그 지식으로 **교육 콘텐츠를 제작하고 학습 현황까지 추적**하는 파이프라인의 **인터랙티브 데모**입니다.

**▶ 라이브 데모: https://mcb-ai365.github.io/ai365.ai.agent.kd/**

> ⚠️ **이 저장소는 순수 프런트엔드 데모입니다.** 백엔드·실제 API 연동은 없으며, 모든 데이터는 가상의 시드이고 모든 동작(수집·판정·업로드·생성)은 브라우저 안에서 시뮬레이션됩니다. 등장하는 문서·계약·이메일·URL은 전부 예시입니다.

## 워크스페이스 3종

| 워크스페이스 | 하는 일 |
|---|---|
| **교육 에이전트** | 외부 문서 수집 → 저작권 판정(5레벨·룰 테이블) → 사람 검토 → 비가역 적재 → RAG·Viva 동시 배포 |
| **콘텐츠 스튜디오** | YouTube 링크 수집(원본 미복제) → 사람 승인(근거 필수) → 텍스트 추출 → **영상 재제작 · 신규 교육 문서 · 기존 문서 업데이트** → 전용 적재 |
| **교육 대시보드** | Viva Learning 학습 기록 × 조직 데이터 - 이수율·마감 관리·출처별 성과 (Graph Employee Learning API 필드에 1:1 대응) |

## 핵심 설계 원칙

| 원칙 | 의미 |
|---|---|
| **업로드는 비가역** | 적재물은 회수·삭제 기능이 존재하지 않음 - 안전장치는 사전 게이트(원본 대조·취소 가능한 업로드 대기)로만 |
| **5레벨 판정** | L1 자유 / L2 조건부 / L3 불명(보호가 기본값) / L4 명시 제한 / L5 접근통제(수집 차단·기록 후 폐기) |
| **표준 카탈로그 우선** | 라이선스 표기를 코드 매칭으로 먼저 판정(32항목), AI 정밀 분석은 카탈로그 미스만 |
| **레벨 상향은 라이선스로만** | 이용 가능 = 기본 레벨 ⊕ 권리 원장의 유효 계약 ⊕ 조직 정책 - 애매하면 항상 보수적으로 |
| **동시 배포, 분리 불가** | SharePoint 적재 순간 RAG·Viva에 함께 전파 - 적재 자격은 3용도(열람·AI·교육) 전부 충족 필요 |
| **재구성은 별개의 권리** | 적재 3용도로는 2차적저작물을 만들 수 없음 - 스튜디오의 소재는 '근거를 남기고 승인된 추출 텍스트'뿐, 승인 관문 하나가 모든 산출물의 권리 근거 |
| **파이프라인이 다르면 전부 나눈다** | 문서와 영상·생성물은 수집 소스·권리 원장·설정·적재 위치를 각각 분리 |

## 화면 구성

- **교육 에이전트** - 검토 대기(우선순위 정렬·일괄 승인·키보드 J/K/A/H/R) · 수집 로그 · 업로드 대기(취소 가능한 마지막 구간) · 적재함 · 보류 · 권리 원장(계약+표준 카탈로그) · 감사 로그, 설정(정책 드라이런·수집 소스·표기 키워드·분류/폴더/파일명·연동)과 알림 드로어
- **콘텐츠 스튜디오** - 링크 수집함(승인 근거 3종: CC-BY 확인/자사 채널/권리자 허락) · 생성 스튜디오(질문 카드) · 게시 현황(추출 텍스트·영상·문서 분리 적재, 카운트다운·취소) · 사내 문서함(자사 저작물, 버전·다운로드) · 재구성 허락 원장
- **교육 대시보드** - KPI(증감·스파크라인) · 부서별/팀 진도(평균 기준선) · 주간 추이(SVG) · 마감 임박·초과 명단 · 출처별 성과 비교 · 스킬 분포 · 배정자별 현황

## 기술

의존성 없는 **단일 HTML 파일**(순수 HTML+CSS+JS). 상태 머신·룰 테이블(R01~R15)·표준 카탈로그·판정 엔진·생성 파이프라인·대시보드가 전부 파일 안에 있으며, `[BACKEND]` 주석이 실제 서비스에서 API로 대체될 지점을 표시합니다.
